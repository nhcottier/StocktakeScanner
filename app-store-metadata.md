## Description
Stocktake Scanner is a simple stocktake tool for teams who need to capture product counts quickly and export them to Excel.

Use the camera to read bin locations and product labels, review the detected product code and description, enter the quantity, then save the count. Stocktake Scanner keeps the workflow focused so you can move through shelves, bins, and product lines without extra paperwork.

Key features:
- Scan bin locations with the camera.
- Read product labels using on-device text recognition.
- Treat the top line of a label as the product code.
- Use the remaining label lines as the product description.
- Manually edit product codes, descriptions, notes, and quantities.
- Enter large quantities directly with the keyboard.
- Group counts by bin location and product code.
- Export stocktake results to an Excel workbook.
- Keep a local backup of stocktake data.
- Save an iCloud Documents backup when iCloud is available.

Stocktake Scanner is built for practical warehouse and stores work: scan, check, count, save, export.
